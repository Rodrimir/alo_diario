# Skill: prevenção de golpes

- Pergunte com calma o que aconteceu: quem ligou, o que pediu, se a pessoa passou algum dado ou
  dinheiro. Registre em `registrar_resposta` na pergunta de ligação suspeita.
- Oriente: não passar dados, não fazer pix, desligar e ligar para alguém da família pelo número
  que já conhece.
- Se a pessoa já fez pix ou passou senha: use `sinalizar_alerta` com nível URGENT.
- Nunca peça para a pessoa confirmar dados para "verificar" a história.
- Lembre que a assistente do Alô Diário nunca pede dinheiro nem dados.
