|===
|Description
|Infraestrutura transversal: segurança, web/erros, OpenAPI, configuração, persistência e logging.  
+
Módulo aberto (todas as classes podem ser usadas pelas features), mas sem nenhuma dependência de feature: `allowedDependencies = {`}.
|Base package
|`br.com.cuida.shared`
|Spring components
|_Configuration properties_

* `b.c.c.s.security.JwtProperties` -- Configuração do JWT (HS256).

_Others_

* `b.c.c.s.security.CurrentUserProvider` -- Lê o usuário autenticado do contexto do Spring Security.
* `b.c.c.s.security.TokenIssuer` -- Emite JWTs HS256 com `sub` = id do usuário e `role` = papel.
|Properties
|* `app.security.jwt.allow-random-secret` -- `java.lang.Boolean`, default `false`. se `true` (só no perfil dev), gera um segredo aleatório quando `secret` está vazio
* `app.security.jwt.issuer` -- `java.lang.String`, default `cuida`. valor do claim `iss`
* `app.security.jwt.secret` -- `java.lang.String`. segredo com pelo menos 32 bytes (`JWT_SECRET`)
* `app.security.jwt.ttl` -- `java.time.Duration`, default `PT1H`. validade do token (`JWT_TTL`, padrão 1h)
