|_Services_

|Bean references
|* `b.c.c.i.AcessoIdosoService` (in Idoso) -- API pública do módulo para os demais: consulta de idosos e checagem de acesso.  
+

|Aggregate roots
|* `b.c.c.q.model.ItemQuestionario` -- Pergunta/atributo que a IA deve cobrir na conversa com a pessoa idosa.
|Events listened to
|* `b.c.c.i.model.IdosoCadastrado` -- Todo idoso nasce com as perguntas sugeridas.
